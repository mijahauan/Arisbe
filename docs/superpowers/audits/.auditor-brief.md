# Shared auditor brief — doc-sweep (workstream B1)

You are a **documentation auditor**. You read your assigned cluster of Arisbe docs and **propose
findings** — you **edit nothing**. Another pass merges all clusters into a docket; the fixes happen
later, gated by the author.

Repo root: `/Users/mjh/Sync/GitHub/Arisbe`. Read the pre-pass first:
`docs/superpowers/audits/2026-07-20-doc-sweep-prepass.md` — it establishes that the **mechanical layer
is already clean** (zero real dead links, no archived-as-live refs, no stray renames). So **do not
hunt dead links** — report a link only if you spot one the pre-pass genuinely missed. Your yield is
**judgment**.

## The finding contract (every finding, one per line)
```
- <file>:<line> · <DIMENSION> · <C|I|M> · <mechanical|judgment> · <one-line defect> · FIX: <one-line suggested fix>
```
A finding with no `file:line` is not actionable — omit it. If your cluster is clean on a dimension,
say so. Write your output file (path given in your dispatch) and nothing else; **change no doc under
audit**.

## The dimensions
1. **dead-refs** *(mechanical)* — only if the pre-pass missed a genuinely broken link/rename.
2. **staleness** *(judgment)* — a claim that looks contradicted by the current codebase/state (an old
   count, a superseded decision, a feature described as absent that now exists or vice-versa). **Name
   the claim and why it looks stale; do not assume** — flag for verification. (Older docs — layout,
   nodes, early specs — are the likeliest carriers.)
3. **overclaim** *(judgment)* — an **asserted terminus** (the "final"-family used AS AN ASSERTION,
   not as discussion/critique of Peirce's *final opinion* doctrine — most "final opinion" hits in the
   FIDELITY/EXAMINATION docs are legitimate critique and are NOT findings), a **flagged gloss presented
   as settled**, or **`institutionalize` misused** (claiming one individual/instance institutionalizes —
   it "cannot occur in an individual"). The assert-vs-discuss judgment is the whole point.
4. **named-entity consistency** *(judgment — the flagship)* — a named entity described inconsistently
   across docs. **The three EPG roles — Graphist / Grapheus / Agonothetes — are the headline case.**
   Record, per doc you see them in, *what informative components* that doc's description contributes
   (role, stance, what it does, its mechanical reduction). **Resolution is HARMONIZATION INTO ONE
   VISION, not deletion** — the components are complementary and get synthesized (later, in the
   cross-cutting pass) into one account seated in the canonical frame. Canonical frame:
   `THE_COMMENS_AND_THE_COMMUNITY.md` §3 (roles as a good-regulator *model* of the institution:
   proposer / defender / judge) + CLAUDE.md's `agon_llm` bullet (Graphist·doubt / Grapheus·defense /
   Agonothetes·judge). Report each doc's role-description with its `file:line` so the harmonizer has
   the raw components.
5. **vocabulary drift** *(mechanical-ish)* — old/inconsistent use of the settled terms: **UoD** =
   the per-instance internalized/attested model *inside the membrane*; **commens** = the un-possessed,
   participation-sustained social construct *outside* it; **mention-ascent** = the retired-name-for
   "second-order crossing". Flag drift in a touched doc.
6. **dedup** *(judgment)* — the same concept phrased differently in ≥2 places. (Pure redundancy →
   pick-one-and-point. Complementary components → that's dimension 4, harmonize.)
7. **readability** *(judgment — book-tier docs only)* — dense unexplained shorthand, a bare `§N`
   cross-*doc* reference (convention: name the target doc), or a shorthand not expanded on first use in
   a book chapter.

## Tiers
- **DEEP (book chapters):** all seven dimensions.
- **LIGHT (non-book docs):** dimensions **2 (staleness), 4 (named-entity, esp. EPG roles), 5
  (vocabulary)** — plus dead-refs only if the pre-pass missed one. (Non-book docs skip overclaim,
  dedup, readability unless something jumps out.)

Severity: **C** = misleads a reader about what Arisbe is/does; **I** = a real inconsistency or stale
claim a careful reader would trip on; **M** = polish. Keep it calibrated — do not inflate.
