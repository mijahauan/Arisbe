# Documentation Sweep (Workstream B1) Implementation Plan — the audit half

> **For agentic workers:** this plan's Phase A (the audit → docket) is **controller-orchestrated** (the controller runs the pre-pass and dispatches auditor subagents directly — it is not an SDD implementer-per-task build). Phase B (the fixes) is authored as a *separate* plan derived from the docket this plan produces, and executed with superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Produce a tiered, evidence-anchored **audit docket** of real defects across the 87 top-level `docs/*.md`, and surface the judgment calls to the author — so the mechanical fixes (a follow-on plan) and the author's rulings can proceed from a concrete work-list rather than a blind guess.

**Architecture:** A mechanical pre-pass (link-checker + grep candidate lists) feeds parallel cluster-auditor subagents (deep on book chapters, light on non-book), whose structured findings merge into one docket; a final cross-cutting pass catches drift that spans clusters (the EPG-role case). Design of record: [docs/superpowers/specs/2026-07-20-doc-sweep-design.md](../specs/2026-07-20-doc-sweep-design.md).

**Tech Stack:** Markdown; git; grep/bash for the pre-pass; Agent subagents (sonnet) for the audit.

**The spec governs.** The seven audit dimensions, the tier discipline, the fix boundary, and the harmonize-into-one-vision rule for named entities are defined in the spec; this plan orchestrates the audit that feeds them. If plan and spec disagree, the **spec governs** — flag it.

## Global Constraints

- **The audit produces findings, not edits.** Phase A changes **no** doc under audit. Its only writes are the pre-pass file, the per-cluster findings files, and the committed docket — all under `docs/superpowers/audits/`.
- **Auditors propose, never edit.** A cluster-auditor that edits a doc under audit has violated its contract.
- **Tier discipline:** book chapters (in `docs/_quarto.yml`) → all 7 dimensions, deep. Non-book top-level docs → dimensions dead-refs / staleness / vocabulary only, light.
- **Coverage is exact:** every top-level `docs/*.md` lands in **exactly one** cluster; `archived/`, `_book/`, `superpowers/`, `references/`, and non-prose subdirs are out.
- **Evidence-anchored findings:** every finding carries `file:line`, its dimension, a severity, a `mechanical|judgment` tag, and a suggested fix. A finding without a `file:line` is not actionable — reject it.
- **The named-entity resolution is harmonization, not deletion** (spec ruling 5): where variants carry complementary informative components (the EPG roles), the proposed fix synthesizes one vision seated in doctrine §3 — it never just picks one and drops the rest.
- **Docs only; no `src/` change.** Commit trailer, verbatim: `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`

## Task 1: The mechanical pre-pass

**Files:** Create `docs/superpowers/audits/2026-07-20-doc-sweep-prepass.md`.

**Interfaces:** Produces the candidate-defect lists the Task-2 auditors read so they don't re-find grep-able defects.

- [ ] **Step 1: Link integrity over all 87 docs.** For every top-level `docs/*.md`, extract each `](target)` and resolve it: a bare `#anchor` against that file's own headings; a `file.md#anchor` against the target file's headings; a `file`/`path` against the filesystem. Emit every unresolved target as `SOURCE.md:LINE -> MISSING target`.

```bash
cd /Users/mjh/Sync/GitHub/Arisbe
{
  echo "# Doc-sweep pre-pass — $(git rev-parse --short HEAD)"
  echo "## Dead/again links (file or #anchor target absent)"
  for f in docs/*.md; do
    grep -oEn "\]\(([A-Za-z0-9_./#-]+)\)" "$f" | sed -E 's/\]\(//; s/\)$//' | while IFS=: read -r ln t; do
      case "$t" in
        \#*) sec="${t#\#}"; grep -qiE "^#+ .*" "$f" && \
             { hdr=$(grep -oE "^#+ .*" "$f" | sed -E 's/^#+ //; s/[^A-Za-z0-9 -]//g; s/ +/-/g' | tr "[:upper:]" "[:lower:]"); \
               echo "$hdr" | grep -qx "$sec" || echo "$f:$ln -> MISSING anchor $t"; } ;;
        *#*) g="docs/${t%%#*}"; [ -e "$g" ] || [ -e "${t%%#*}" ] || echo "$f:$ln -> MISSING file $t" ;;
        http*) : ;;
        *) [ -e "docs/$t" ] || [ -e "$t" ] || echo "$f:$ln -> MISSING $t" ;;
      esac
    done
  done
} > docs/superpowers/audits/2026-07-20-doc-sweep-prepass.md
```

## Task 3: Merge + cross-cutting pass → the docket

**Files:** Create `docs/superpowers/audits/2026-07-20-doc-sweep-docket.md`.

**Interfaces:** Consumes the 8 cluster files + the pre-pass; produces the single tiered docket that the fix plan (Task 4) is authored from.

- [ ] **Step 1: Cross-cutting pass.** Dispatch one auditor (Agent, `general-purpose`, `sonnet`) reading all 8 `.cluster-*.md` files + the pre-pass's vocabulary/EPG/dedup candidate sections. Its job: find **cross-cluster** defects the per-cluster reads structurally cannot — dedup (a concept stated in ≥2 clusters), named-entity drift (the EPG roles across clusters E/C/D), and vocabulary inconsistency. For the EPG roles specifically, it drafts the **proposed harmonized one-vision account** (absorbing each doc's informative components, seated in doctrine §3) as a candidate for OQB2. Output: `docs/superpowers/audits/.cluster-X-crosscutting.md`, same finding contract.

- [ ] **Step 2: Merge into the docket.** Assemble `2026-07-20-doc-sweep-docket.md`: a header (commit sha, doc-count, cluster map), then **Tier 1 — Mechanical** (dead-refs, vocabulary-conformance, pure-redundancy dedup) grouped by fix-batch and ordered by severity, then **Tier 2 — Judgment (author decision)** (borderline overclaims, the EPG-role harmonization + its proposed one-vision draft, book-membership recommendations, substantive readability rewrites). Each finding keeps its `file:line` and `mechanical|judgment` tag. End with a **counts summary** (findings per dimension, per tier) and an explicit **coverage line** (all 87 docs audited; N clean).

## Notes for the executor

- **Phase A writes only under `docs/superpowers/audits/`.** No doc under audit is touched until the fix plan (Phase B) runs — and then only per the docket + the author's Tier-2 rulings.
- **The audit is discovery.** Do not pre-judge findings into fixes; the fix plan is authored from what the audit actually finds, and the author rules Tier 2 before any judgment fix lands.
- **If the pre-pass link-check script misfires** on an edge case (an odd link form), treat its output as candidate-only — the cluster-auditors confirm dead links against the real files; a false positive there is harmless, a false negative is caught by the auditor's own read.
- **Scope discipline:** only `docs/*.md` top-level is audited; a finding about `archived/`, `_book/`, or `superpowers/` is out of scope — note and drop.
