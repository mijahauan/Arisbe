**The voice** (ruled 2026-07-26, [VISION_AND_SCOPE.md](../VISION_AND_SCOPE.md)
§8): each letter voices Arisbe as **a proposition scribed into the wider
Endoporeutic Game**, to a competent interlocutor, in the recipient's own
vocabulary — it *proposes* rather than asserts, cites the peels already played
(pre-registered priors, run logs), and **invites refutation as a lawful move**:
a competent refutation would be the game working, not the game lost.
Publication and outreach are the only route to a judgment the project cannot
make for itself, since judgment is objectivated, never owned
([THE_COMMENS_AND_THE_COMMUNITY.md](../THE_COMMENS_AND_THE_COMMUNITY.md) §2(c)).
